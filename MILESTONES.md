# Milestones

The rollout order is in [SPEC §8](SPEC.zh-CN.md). This document fills in the half missing from the spec: **what counts as done.**

**"Written" does not equal "done".** Writing Phase 0 took about an hour, getting it done was three hours later — with three false positives in between, exposed entirely by testing, one of which was a **silent security hole**. Therefore, every acceptance criterion below is falsifiable and must be actually observed; "the code is written" is not accepted.

## How to keep this file from rotting

menxia's own ledger stalled for 7 commits, during which metrics remained in a triggered state. The conclusion from that post-mortem is worth copying over as-is: **the lesson is not "forgot", it is that ledgering has no trigger** — feature commits and measurement commits walk their own separate paths, connected in between solely by discipline.

**The trigger was installed on 2026-07-29 along with Phase 1** (running `scripts/print-milestones.mjs` at the end of `npm test`, parsing the status lines from this file and printing them, no hardcoding — hardcoding equals building another drifting replica). This debt is paid off.

One rule that still holds: **seeing "not started" untouched must be treated as "not verified" rather than "definitively accurate"**. The trigger only guarantees you will see this table every time you run tests, it does not guarantee the table is correct.
